# Wiki pages

Texts to publish on Wikipedia. AWB-X sends the documentation page's URL in its User-Agent
(`settings.appconfig.DEFAULT_USER_AGENT_CONTACT`), so the page must exist before AWB-X is used
widely.

| File | Publish at | Notes |
|---|---|---|
| `AWB-X.wikitext` | https://en.wikipedia.org/wiki/Wikipedia:AWB-X | Check the HTML comments (edit summary wording, source link) first. If you publish it elsewhere, change `DEFAULT_USER_AGENT_CONTACT` to match. |
